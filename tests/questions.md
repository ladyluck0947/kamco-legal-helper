# 테스트 질문 (PLAN 17번)

- **기본 질문 1~20번:** PRD 3장 성공 기준(시간·정확도·근거 제시율)을 측정하는 질문. 작성자 검토 완료(2026-10-28).
- **심화 질문 21~30번:** 여러 사정이 얽혀 판례로 판단해야 하는 실무 상황. 작성자 요청으로 추가했으며, 성공 기준과 별도로 측정한다. 작성자 검토 완료(2026-10-28).
- 작성: Claude 초안 → **작성자(임동욱) 검토·보완 후 확정** (PRD 3장)
- 정답 기준의 출처: `data/laws.json`(국유재산법·시행령, **2026. 8. 20. 시행**), `data/cases.json`(대법원 판례 16건)
- 모든 질문이 위 자료에 근거가 있는 질문이다 (PRD 3장, 검토 지적 2-2 B).
- 정확으로 인정하는 기준: **결론과 근거 조문(또는 판례)이 모두 맞아야** 정확 (PRD 3장, 검토 지적 2-1 B)
- "쉬운 말" 표시: 법률 용어를 모르는 신입 직원처럼 일상어로 물어본 질문 (DESIGN.md 3장 "자료 찾는 방법" 확인용)

## 참고

- 기본 질문 중 쉬운 말 질문: 12개 (1, 3, 6, 8, 9, 10, 12, 13, 16, 17, 18, 20)
- 기본 질문 중 판례가 정답 근거인 질문: 5개 (4, 6, 7, 8, 11)
- 심화 질문 21~30번은 모두 판례가 정답 근거다. 판례 중 상당수가 구 국유재산법 조문 번호를 쓰므로, 21번처럼 현행법과 판례가 다른지 꼭 함께 확인한다.
- 시행령 제29조(사용료율), 제40조(처분 방법), 제55조(분할납부)는 조문이 길어 정답 기준에는 핵심 부분만 적었다. 세부 요율·예외 사유는 검토 때 원문으로 확인한다.
- 아직 넣지 않은 자료(행정심판 재결례, 공개 유권해석)에 관한 질문은 자료를 추가한 뒤 보완한다.
